\subsection{CPU architecture}\label{subsec:cpu-architecture}

CPU architectures are typically optimized for serial processing, possibly in multi-threaded scenarios. The architectures contain multiple levels of cache (L1, L2, L3) to reduce the latency of memory accesses, with nontrivial cache coherence protocols and costly synchronization mechanisms. % TODO find sources to rewrite this better
Modern CPUs also support SIMD (Single Instruction, Multiple Data) instructions to perform vectorized operations on multiple data elements concurrently that can significantly speed up numerical computations when the data is properly aligned and the data can be organized so contiguous blocks of data have no inner dependencies.
